| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Relatando uma Vulnerabilidade

A segurança é uma prioridade para nós. Se você descobrir uma vulnerabilidade de segurança, por favor:

### 🔒 **Reporte Responsavelmente**

1. **NÃO** crie uma issue pública sobre a vulnerabilidade
2. Envie um email para: [opta.labs.ia@gmail.com]
3. Inclua o máximo de detalhes possível:
   - Descrição da vulnerabilidade
   - Passos para reproduzir
   - Impacto potencial
   - Versão afetada

### ⏱️ **Tempo de Resposta**

- **Confirmação inicial:** 24-48 horas
- **Avaliação detalhada:** 5-7 dias úteis
- **Correção e release:** Conforme gravidade

### 🛡️ **Processo de Correção**

1. Confirmamos o recebimento
2. Investigamos e validamos
3. Desenvolvemos uma correção
4. Testamos a solução
5. Lançamos update de segurança
6. Divulgamos responsavelmente

### 🏆 **Reconhecimento**

Contribuidores que reportam vulnerabilidades de forma responsável serão:
- Creditados no CHANGELOG (se desejarem)
- Mencionados no hall da fama de segurança

## Diretrizes de Segurança

### 🔐 **Para Desenvolvedores**

- **Tokens e API Keys:** Sempre use variáveis de ambiente
- **Webhooks:** Implemente verificação de tokens
- **Logs:** Não registre informações sensíveis
- **Criptografia:** Use HTTPS para todas as comunicações

### 🛡️ **Para Usuários**

- Mantenha seus tokens seguros
- Use senhas fortes para contas integradas
- Atualize regularmente o N8N e dependências
- Monitore logs de acesso

## Conformidade

Este projeto segue:
- **LGPD** (Lei Geral de Proteção de Dados)
- **Boas práticas de segurança** da OWASP
- **Padrões de segurança** do N8N
- **Diretrizes** do WhatsApp Business API
